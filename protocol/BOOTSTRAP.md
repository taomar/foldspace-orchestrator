# FoldSpace bootstrap

**Revision: 2.1.4 - 6 September 2026**

Start here in the target repository; no clone/attachment. Fetch details on
demand. Documentation, not a runtime or host repair.

## First response

Acknowledge intent/run mode; reuse valid answers and optional
[prestaged inputs](RUN_CONFIGURATION.md#optional-prestaged-interview-inputs).
Ask missing/conflicting/unsupported items. Unapproved inputs need validation,
summary and final approval, not dispatch.

"Continue pending work": use context or known compact state/checkpoint/task index
to derive candidates/acceptance; ask focused selection if ambiguous. No invented
tasks or rewritten backlog. Unknown/inaccessible record: ask location/access or
an independent model/budget question. No preapproval discovery worker.

## Advance without monopolizing the session

**One question at a time means at most one outstanding unanswered question.**
Reconcile delivered answers (including synchronous question-tool results),
steering and completion/delivery events; take the next permitted bounded read,
supported question, review/final approval request or approved action.
No extra "continue" or status-only exit. Naming the next question is not asking it.
Missing dispatch approval does not block clarification. Workers execute valid
assignments, not restart interviews.

Use context or one known-short targeted read per missing fact;
advance from its result. No scans, catalogs, chained research, polling or
whole-worker waits. Public reference GETs are not inference; send no private data.

Yield for real missing input/evidence/capability/authority after
eligible independent steps: state phase, last action, exact gap/owner and
supported resume event/manual action. Follow actual host question lifecycle:
suspended is not completed; answered is not waiting. Request normal access
permission. No invented self-wake or loops.

## Approval is still mandatory

Before any worker or direct external LLM call: approve providers/families/exact
IDs, role defaults/fallbacks; per-model minimum/default/maximum on verified
supported order or verified accepted N/A; external consent; aggregate caps/units,
allocations, concurrency, retries/stop policy; final run approval. External calls
default denied. No silent defaults, conversions, unlimited budget or guessed N/A.
Uncapped scope needs explicit opt-in/risk acceptance. Verify required controls or hold
affected work for an approved demonstrable alternative.

## Localize, then continue building

After approval, reserve budget; use proven nonblocking workers or an approved
manual path. Setup pins a commit, previews conflicts, copies linked references/
LICENSE without overwrites, adapts instructions/state separately, records
URLs/commit/revision/hashes and verifies discovery. Continue the actual objective.

New runs reconfirm settings without erasing owners, operations, authority,
resource exclusions, charges or reservations. Same-run approval survives.
Reserve parent budget; descendants inherit/tighten. Reconcile before replay.
Do not recover a stalled host by feeding its blocked queue.
